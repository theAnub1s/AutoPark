Conoce AutoPark

Estacionarse debería ser más sencillo

AutoPark conecta a conductores que buscan un lugar disponible con propietarios que desean administrar y publicar sus espacios de estacionamiento desde una misma plataforma.

Ver servicios Contacto

Nuestro propósito

1

Encontrar

Facilitar la búsqueda de estacionamientos por zona, precio y disponibilidad.

2

Reservar

Mostrar información clara para reservar con mayor seguridad y menos tiempo perdido.

3

Administrar

Dar a propietarios herramientas para publicar y gestionar disponibilidad y horarios.

Proyecto académico

AutoPark se desarrolla como un sitio web multipágina responsive, utilizando HTML5, CSS, JavaScript, Bootstrap 5 y control de versiones con Git y GitHub.
